# 洛月站点 · 使用与维护手册

> 这份手册随仓库一起备份（GitHub 上也能看），换电脑 `git clone` 下来就有。
> 只有 `tools/config.json`（本机路径）、`_trash/`（回收站）这类是本机专属，不跟仓库走。

## 1. 这个站是什么

```
content/  ──(node tools/build.js)──>  静态页面（根目录的 index.html、posts/、about/ …）
   │
   ├─ 写作台（本地 127.0.0.1:4173）保存时自动重建
   └─ git push ──> GitHub Pages 对外提供
```

- 没有数据库、没有后端服务，站点就是一堆静态文件。
- 写作台只在你本机跑，负责把 `content/` 变成页面。
- 所有内容都是纯文本：Markdown 和 JSON。

## 2. 换电脑 / 重装系统：三步

### 2.1 装 Node.js

到 https://nodejs.org 下载 **LTS** 版，一路下一步。

装完在命令行敲 `node -v`，能出版本号就行（需要 18 或更高）。

### 2.2 复制文件夹

两种方式都行：

- **复制整个文件夹**：最省事，连本机配置和回收站一起带走
- **`git clone`**：只拿仓库里的内容（页面、文章、写作台代码、这份手册），
  `tools/config.json` 和 `_trash/` 需要在原机器上另存一份

路径带空格、带中文都没关系。

### 2.3 双击 `tools\setup.bat`

它会：

1. 检查 Node.js，没装就直接打开下载页
2. 跑一次**依赖体检**（Git、文件、写权限、远端地址），缺什么就把对应安装页打开
3. 重建桌面快捷方式「洛月写作工具」
4. 启动写作台

> 如果不想建快捷方式，以后直接双击 `tools\start.bat` 也行。

### 2.4 恢复推送权限（二选一）

**A. 你备份过 `.ssh` 文件夹**：整个复制回 `C:\Users\你的用户名\.ssh`，不用重新配。

**B. 没有备份**：双击 `tools\git-ssh-setup.bat`，它会生成密钥、写好 `~/.ssh/config`、打印公钥；
把公钥贴到 https://github.com/settings/keys 的 **New SSH key**。

验证：命令行敲 `ssh -T git@github.com`，看到 `Hi 用户名!` 就成了。

> 不想折腾 SSH 也行：推送时用 **HTTPS 地址 + 访问令牌**，见 4.2。

## 3. 日常：打开写作台

双击桌面「洛月写作工具」，或 `tools\start.bat`。
浏览器打开 `http://127.0.0.1:4173/admin/`，那个黑色窗口不能关。

写作台有 10 个标签：

| 标签 | 做什么 |
|---|---|
| 文章 | Markdown 编辑器、封面、置顶、链接短名、实时预览 |
| 站点 | 站名、首屏文案、看板娘、页脚、功能开关、各页导语 |
| 关于 | 名字、档案、喜欢的角色、联系方式；档案可填「夜间内容」随昼夜切换 |
| 说说 | 一条一句 + 可选配图，自动带你的头像 |
| 相册 | 建多个相册，上传照片写说明；点开可放大 |
| 友链 | 头像 + 站名 + 简介卡片；没有友链时的提示文字也能改 |
| 台词 | 收藏句子和出处 |
| 音乐 | 粘贴网易云链接自动解析歌名；进度条、音量、歌单；可开关「进站自动播放」 |
| 环境 | 一键体检：Node / Git / 文件 / 权限 / 远端，缺什么给安装链接 |
| 发布 | 仓库地址、令牌、提交、推送、拉取、日志 |

**保存任何一项都会自动重建整站。**

### 3.1 写一篇新文章

1. 「文章」→ 左上「＋」
2. 填标题、日期、分类、封面日文、配色，勾不勾置顶看心情
3. **日期时间**：点输入框会弹出自己做的日历（不是浏览器那种），可以选年月日 + 时分秒，
   左下角「现在」一键填入当前时间，「清除」清空
4. 正文用 Markdown；上面那排按钮会帮你插入小标题、对白、便签、图片
4. 点「预览」看排版，点「保存」

保存后自动生成 `posts/<短名>/index.html`，首页、列表、归档、sitemap 一起更新。

> **链接短名**：网址最后一段，只能英文/数字/中文，留空就用日期（`/posts/2026-11-02/`）。

### 3.1.1 插链接

正文工具栏里有个「🔗 文字链接」。选中一段字，点它（或按 `Ctrl + K`），填上地址，就变成可点的链接。
说说、台词、关于页的段落也支持同样的写法：`[显示的文字](https://example.com)`。

### 3.1.2 全屏写作

正文工具栏右侧有「⛶ 全屏写作」，点开占满整个窗口、字号更大；按 Esc 或再点一次退出。

### 3.1.3 各处的小链接按钮

所有文本框（标题、摘要、说说、台词、进站提示等）上方都有一条「🔗 插入链接」，用法和正文一样。

### 3.2 改旧文章 / 删文章

左边点标题 → 改 → 保存。删除会先移进 `_trash/`，左下「回收站」里可以：

- **恢复**：放回 `content/posts/`
- **永久删除**：真正删掉文件，不能恢复

回收站只存在本机，不进 git；想长期保留就先恢复再提交。

### 3.3 说说、相册、友链

友链头像、相册图片等输入框旁有「↑ 上传」按钮，可直接选本地图；头像会自动压到 400px。

友链的头像、相册的图片等输入框旁边都有「↑ 上传」按钮，可以直接选本地图（头像会自动压到 400px）。

- **说说**：一句话也行，日期时间同样点输入框选（支持到秒，「现在」一键填）；
  配图每行一个路径，也可以用「＋ 上传 / ＋ 链接」。
- **相册**：先「＋ 新相册」，日期时间点输入框选；再上传照片、写说明；相册页是瀑布流，点图放大。
- **友链**：填站名、头像、链接、简介。没有友链时页面显示你写的那句提示。

---

### 3.4 图片会自动压缩

写作台里所有「上传」按钮都带自动压缩，你只管选图：

| 用途 | 处理 |
|---|---|
| 文章封面 / 正文配图 / 说说 / 相册 | 最长边 1600px、JPEG 质量 82 |
| 头像 | 最长边 400px |
| 小于 150KB 的图 | 原样上传，不折腾 |
| 透明 PNG | 保留 PNG，只缩尺寸 |
| GIF / SVG | 不处理 |

上传完成会提示体积，例如 `已压缩 3.2MB → 240KB（1200×1800）`。
原图不用留，git 里有历史，随时能找回。

### 3.5 音乐

- **加网易云曲目**：粘贴歌曲链接 →「解析并添加」。VIP / 版权曲会被标记「⚠ 放不出来」，播放失败会自动跳下一首。
- **加本地音频**：「＋ 上传本地音乐」，支持 mp3 / m4a / ogg / wav / flac / aac，文件存到 `assets/audio/`。
- **排序**：按住每行左边的 ⠿ 手柄拖动，或者用 ↑ ↓ 按钮；左侧数字就是播放顺序。
- **音量**：「进站初始音量」滑杆决定访客第一次听到的音量。
- **自动播放**：可开关；浏览器首次可能要求点一下才会响。

### 3.6 回收站与永久删除

写作台左下「回收站」：列出删掉的文章（标题、短名、日期），可恢复或永久删除。
永久删除前会二次确认，删了就找不回来了。

### 3.7 环境检查与清理

- 「环境」标签：检查 Node / Git / 站点文件 / 写入权限 / 远端 / 端口 / SSH，缺什么给安装链接
- 「清理未用的上传文件」：删除 `assets/audio` 和 `assets/img/posts` 里没被任何文章/说说/相册引用的文件，
  并且**不会动已经提交到 git 的文件**

---

### 3.8 进站提示弹窗

写作台 →「站点」→「进站提示弹窗」，可以改标题、正文（一行一段）、两个按钮的文字和「以后不再提示」。

弹窗只在自动播放被浏览器拦下时出现；访客勾了「以后不再提示」就不再弹。

### 3.9 桌面快捷方式

打开写作台时，如果桌面上还没有指向 `start.bat` 的快捷方式，会弹一个提示卡片：

- **创建到桌面**：马上建一个，以后双击就能打开写作台
- **以后再说**：这次不建，下次还会问
- **不再提示**：存进 `tools/config.json`，以后不再问

识别**不看快捷方式名字**：程序会读取桌面上每个 `.lnk` 的目标路径，跟 `toolsstart.bat` 比对，所以改名、换图标都不影响。

恢复提示：

```
node toolsshortcut-check.js --reset
```

只看状态（不弹窗）：

```
node toolsshortcut-check.js --check
```

「环境」标签页里也能看到状态，随时创建或切换「不再提示」。

## 4. 发布到线上

### 4.1 写作台里

「发布」→ 写一句提交说明 → **提交并推送** → 等 1–3 分钟 → `Ctrl + F5`。

**提交**＝把改动存进本地 git；**推送**＝把本地提交传到 GitHub。发布一般点「提交并推送」。

### 4.2 仓库地址怎么填

两选一：

| 方式 | 地址 | 令牌 |
|---|---|---|
| SSH（推荐） | `git@github.com:用户名/用户名.github.io.git` | 留空 |
| HTTPS | `https://github.com/用户名/用户名.github.io.git` | 必填 |

令牌生成：GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)，
勾 `repo`，生成后复制 `ghp_...`（只显示一次）。

令牌不会存盘，只在推送那一刻临时使用。

### 4.3 命令行方式

```bash
node tools/build.js
git add -A
git commit -m "更新网站"
git push
```

### 4.4 拉取是干什么的

「拉取」= `git pull --ff-only`，把 GitHub 上的改动下载到本地。

只在**同一仓库被别的电脑改过**时才需要：在公司写了并推送 → 回家先点「拉取」再写。
如果只在这一台电脑写作，永远不用点。

失败常见原因：

| 报错 | 意思 | 怎么办 |
|---|---|---|
| `Not possible to fast-forward` | 本地和线上都改了 | 先提交本地改动再拉；仍失败需手动处理冲突 |
| `Your local changes would be overwritten` | 有未提交改动 | 先提交，再拉取 |

### 4.5 推完线上没变

1. 等 1–3 分钟（GitHub Pages 要重建，期间可能短暂 404 或旧版）
2. `Ctrl + F5`
3. 看提交在不在：`github.com/用户名/用户名.github.io/commits/main`

## 6. 出问题了

### 6.1 先跑体检

```bash
node tools/doctor.js
```

会逐项告诉你 Node / Git / 文件 / 权限 / 远端 是否正常，缺什么直接给安装地址。
加 `--open` 会自动打开第一个缺失依赖的下载页。
写作台里也有「环境」标签，是同一套检查。

### 6.2 常见情况

| 现象 | 排查 |
|---|---|
| 写作台打不开 | `node -v` 有没有版本；端口 4173 是否被占（双击 start.bat 会检测） |
| 保存了页面没变 | 看命令行窗口有没有报错；到「环境」里重新检查 |
| 页面 404 | 目录式 URL 必须走服务，不要用 `file://` |
| 图片不显示 | 路径以 `/assets/` 开头；文件名大小写敏感 |
| 推送失败 | 看「发布」日志：地址错 / 令牌过期 / SSH 公钥没加；日志下面会提示具体原因 |
| 音乐放不了 | 少数版权曲网易云会拒；换一首 |
| 想整体回滚 | `git checkout v3-glass` 之类的标签，或 `git log` 找提交 |

## 8. 小词典

| 词 | 意思 |
|---|---|
| slug（短名） | 文章地址最后一段，`/posts/这里的/` |
| front matter | md 开头 `---` 夹着的配置 |
| 构建 | `node tools/build.js`，把 content 变成页面 |
| 目录式 URL | 页面存成 `xxx/index.html`，网址就是 `/xxx/` |
| 置顶 | `pinned: true`，首页/列表/归档都会体现 |
| 体检 | `node tools/doctor.js`，检查依赖齐不齐 |

## 9. 什么进仓库、什么不进

| 进仓库（GitHub 有备份） | 只在本地 |
|---|---|
| `content/` 文章与配置 | `tools/config.json`（本机路径、仓库地址） |
| `assets/` 图片与音频 | `_trash/` 回收站 |
| 生成好的所有页面 | `tools/*.log`、`*.bak` 等日志 |
| `tools/` 里的代码与这份手册 | `preview/` 设计稿 |

所以：

- 文章、图片、音频、代码、手册 → 云端有备份
- 回收站里的删除内容 → 只在本机，换机会丢

## 10. 日常维护清单

| 多久 | 做什么 |
|---|---|
| 每次写完 | 提交并推送 |
| 换电脑 / 重装 | `setup.bat` + 恢复 SSH 或填令牌 |
| 觉得哪里怪 | 先跑 `node tools/doctor.js` |
| 仓库变大 | 环境页「清理未用的上传文件」 |
| 想确认线上 | `Ctrl + F5`，或看 GitHub 的 commits 页 |

## 11. 排查补充

| 现象 | 原因 / 处理 |
|---|---|
| 写作台打不开 | `node -v` 有版本吗；端口 4173 被占时双击 start.bat 会直接打开已有实例 |
| 保存后页面没变 | 看命令行窗口报错；重启 start.bat；再不行跑体检 |
| 时间显示不出来 | 日期字段要选到具体时间；老内容没填时间就只显示日期 |
| 上传同一首歌出现 -1 | 旧版本的问题；现在按内容去重，不会重复；可用「清理未用文件」收尾 |
| 本地音频不能拖进度 | 本地服务需要支持 Range 请求；`start.bat` 启动的服务已经支持 |
| 音乐换页重新播 | 已修：续播基于浏览器会话，首次加载恢复上次位置 |
| 图片太大拖慢首屏 | 上传时已自动压缩；旧图可用 `tools/compress-images.ps1` 批量压一次 |
| 手机端菜单错位 | 已改为宽下拉卡片；若样式没更新，强刷一次 |
